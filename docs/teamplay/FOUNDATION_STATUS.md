## Remaining external gates

The local work is committed and reviewable. Publication requires an authenticated terminal with GitHub network access. From this repository, in that environment:

```powershell
gh auth status
gh repo create georgi-cole/the-big-eye-teamplay --private --source=. --remote=origin --push
```

This creates a **private** repository and runs the normal pre-push hook. If the remote has since been created, inspect it and configure its existing origin instead of recreating it. GitHub CI must pass before treating the native builds and online dependency audit as verified. Debug/simulator builds do not establish signing, purchase readiness or real-device storage isolation.
